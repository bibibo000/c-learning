## 踩过的坑

1. **排序时内外层循环用了同一个变量 `i`**  
   内层 `for(i = b; i < 9; i++)` 会把外层循环的 `i` 改乱，导致排序只跑一轮。  
   → 正确做法：外层用 `i`，内层用 `j`。

2. **插入元素时位置控制混乱**  
   用中间变量 `d` 记录插入位置容易出错。  
   → 正确做法：先把新元素放到数组末尾，再从后往前两两交换到正确位置。

3. **折半查找的前提**  
   数组必须有序才能用二分查找，乱序数组需要先排序。
